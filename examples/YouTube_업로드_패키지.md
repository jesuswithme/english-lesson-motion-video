# YouTube 업로드 패키지 — 영어 문장 확장의 원리

## 1. 영상 제목 추천 (5개)

1. 영어 문장이 길어지는 진짜 원리 | 핵심 문장 + 설명 덩어리 (V-ing·P.P. 한 번에 정리)
2. 긴 영어 문장, 외우지 말고 "기차"로 이해하세요 🚂 명사 설명 vs 동작 설명
3. "You should get the door"에서 시작하는 영어 문장 확장 훈련
4. V-ing vs P.P. 헷갈림 끝! "하는 쪽 vs 받는 쪽" 하나로 해결하는 영어 문장 늘리기
5. 짧게 말하고 한 칸씩 붙이자 | 원어민처럼 영어 문장 늘리는 법 (회화 연습 + 퀴즈)

## 3. 썸네일용 핵심 카피 (3개)

1. **긴 영어 문장 = 짧은 문장 + 🚂칸 2개** — 보조 문구: "외우지 말고 연결하세요"
2. **V-ing? P.P.? 질문 하나로 끝!** — 보조 문구: "하는 쪽 vs 받는 쪽"
3. **영어는 명사 먼저, 설명은 뒤로!** — 보조 문구: "한국어와 순서가 반대인 이유"

## 5. 제작 메모 (원본 대화 대비 보완·수정 사항)

- **get the door**: "초인종·노크 소리에 나가서 문을 열어 주다"라는 관용적 의미를 명시했습니다.
- **without delay**: 문법적으로 맞지만 부모가 아이에게 쓰기엔 딱딱하므로, 회화 팁으로 *right away*를 추가했습니다.
- **with a smile / without delay**: 원본 설명대로 명사가 아닌 동작(get)을 설명하는 칸으로 다뤘습니다.
- **for the man standing outside**: *for the man*은 '누구를 위해' 여는지(동작 쪽), *standing outside*는 *the man*을 설명하는 명사 설명으로 구분해 시각화했습니다.
- **"V-ing = 항상 능동, P.P. = 항상 수동"은 절대 규칙이 아니다**라는 원본의 주의 문구에 구체적 예시(*a sleeping bag* = 용도의 -ing / *fallen leaves* = 완료의 P.P.)를 보충했습니다.
- **something cold to drink**: something/anything 뒤에 형용사가 오는 예외를 회화 연습에 추가했습니다.
